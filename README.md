# UEC Reference Provider
This repository provides a reference implementation of the UEC semantic (SES), packet delivery (PDS) and Security sub-layers. It is as part of the Libfabrics mapping SDR4001. Please see "UEC libfabric mapping specification"

# Goals
* Reference implement of the Libfabric mapping spec, Semantic, PDS and security layers
* Investigate lower-level interfaces in Libfabric (memory management)
* Provide framework to define Linux kernel interface
* Development/integration vehicle for upper-level libraries (*CCL, etc.)
* User/Kernel mode integration options
# Non-goals
* Clarity is more important than performance
* Minimal external dependencies
